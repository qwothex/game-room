The project features a room with a console, a TV, a gamepad, and game cartridges. Games can be played using an interactive gamepad model or your keyboard. It includes titles such as Doom (1993) with different WAD files, as well as remakes of Crossy Road and Donkey Kong (NES), and more. Made with Three.js and GSAP.
